# Steam Release Checklist

This is a planning checklist; none of these items is complete.

- [ ] Create/configure Steamworks app and keep credentials out of source control.
- [ ] Configure development App ID and session subsystem through documented local settings.
- [ ] Validate private lobbies, friend invitations, presence joining, errors, rematch, and return to lobby.
- [ ] Create a packaged Steam test build; verify logs, crash reporting, install/update behavior, and launch options.
- [ ] Confirm original/licensed vehicles, art, audio, fonts, middleware, and third-party notices.
- [ ] Prepare store assets, pricing/release metadata, supported languages, content descriptors, and support contact.
- [ ] Complete Steam content survey, including required AI-content disclosures based on actual shipped content/processes.
- [ ] Run external playtests, controller/input checks, performance testing, and release-candidate regression testing.
- [ ] Archive exact build, source revision, dependency list, and test evidence before release.
